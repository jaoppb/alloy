HTML Test: Lists & <li> Tag Omission

SPEC: WHATWG HTML §13.2.5 / Alloy PRD-008 Tag Omission
PASS: Itens de lista sem tag de fechamento (</li>) são auto-fechados pelo parser do Alloy quando o próximo <li> é aberto, mantendo a hierarquia correta de itens irmãos.
FAIL: Itens sem </li> ficarem recursivamente aninhados uns dentro dos outros.

1. Lista não-ordenada padrão com fechamento explícito (<ul>)

  • Primeiro item da lista
  • Segundo item da lista
  • Terceiro item da lista

2. Lista ordenada com omissão de fechamento </li> (Tag Omission)

  1. Item 1 (sem tag de fechamento)
  2. Item 2 (sem tag de fechamento)
  3. Item 3 (sem tag de fechamento)

3. Lista aninhada

  • Nível 1 - Item A
  • Nível 1 - Item B
    • Nível 2 - Subitem B.1
    • Nível 2 - Subitem B.2
  • Nível 1 - Item C

CSS Test: Text Alignment

SPEC: CSS Text L3 / Alloy core/css B4
PASS: text-align alinha as linhas à esquerda, no centro, à direita e com espaçamento justificado (distribuindo espaços entre palavras ao longo da linha de 320px).
FAIL: Linhas não alinhadas na direção especificada ou justificação não calculando os intervalos entre palavras.

1. text-align: left (inicial)

Texto alinhado à esquerda dentro da caixa de 320px.

2. text-align: center

Texto centralizado horizontalmente dentro da caixa.

3. text-align: right

Texto ancorado à direita da caixa.

4. text-align: justify

O alinhamento justificado ajusta o espaçamento das palavras para que cada linha ocupe exatamente a largura de margem a margem da caixa delimitadora.

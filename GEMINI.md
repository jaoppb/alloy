# GEMINI.md

This repository keeps a single AI-agent guidance file to avoid two instruction sets drifting apart: **`CLAUDE.md`**.

Read it in full before making any change here. It applies identically regardless of which agent you are — crate map,
layering rules, Object Calisthenics, the `just gate` workflow, and directives folded in from past review feedback (naked
primitives, `arch-lint.toml` extension over reinvention, `tracing`-only logging, `thiserror`-first errors, layer
placement, stale CI action pins, checkable PRD/ADR claims, ADRs written with the code). Do not duplicate its content
into this file; update `CLAUDE.md` instead and let this pointer stay a pointer.

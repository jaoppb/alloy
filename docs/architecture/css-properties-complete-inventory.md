## 2. Roteiro Estratégico de Implementação em Tiers para o Alloy

Para atingir um motor CSS completo sem comprometer a arquitetura ("Skeleton and Muscle", Clean Code e Object
Calisthenics):

1. **Tier 1 (Base CSS 2.1 & Fluxo Normal):** Conclusão de posicionamento clássico
   (`position: relative|absolute|fixed|sticky`, `top/right/bottom/left`, `z-index`, `float`, `clear`), estilos de borda
   (`border-style`, `border-color`, `outline`), e `overflow` básico (`hidden`, `scroll`, `auto`).
2. **Tier 2 (Grid Layout L1/L2):** Módulo `core/css/src/infrastructure/layout/grid.rs` espelhando `flex.rs` com suporte
   a `grid-template-columns`, `grid-template-rows`, `fr` units, `gap`, e alinhamentos bidimensionais.
3. **Tier 3 (Propriedades Lógicas & i18n):** Mapeamento no estágio de cascade de `margin-inline-*`, `padding-block-*`,
   `inline-size` para os eixos físicos dependendo de `writing-mode` e `direction`.
4. **Tier 4 (CSS Variables & Cascata Avançada):** Suporte à sintaxe `--*` e função `var()` no estágio de cascade
   (`author_rules.rs`), além de regras at `@layer` e `@container`.
5. **Tier 5 (Decorações Visuais & Rasterização):** `border-radius`, `box-shadow`, `opacity`, gradientes CSS
   (`linear-gradient`, `radial-gradient`) no `DisplayList` do `core/graphics`.
6. **Tier 6 (Animações & Transições):** `transition-*` e `animation-*` integrados ao event loop do motor e pipeline de
   ticks de frame.
